# HealthGuard
### Clinician-Connected Health Record Intelligence Platform
**© 2026 EVOLVEX IT SOLUTIONS PVT. LTD.** · Varanasi, Uttar Pradesh, India

HealthGuard turns messy medical documents into structured, traceable health records
and connects patients with verified clinicians. AI extracts, organizes, summarizes,
flags and assists — a verified clinician remains responsible for clinical interpretation.

## Site structure
29 static pages — **every component and feature of the platform has its own page**,
each with the animated HealthGuard logo, full header navigation and the EVOLVEX
footer. Generated by `build.mjs` from `src/layout.mjs` + `content/*.mjs` so the
chrome is pixel-identical everywhere.

| Family | Pages |
|---|---|
| Home & hub | `index` · `platform` |
| Decks | `patient-deck` · `doctor-deck` · `admin-deck` |
| Document AI | `report-upload` · `ocr-engine` · `ai-pipeline` · `ai-models` · `report-intelligence` · `health-timeline` |
| Triage & Consult | `ai-triage` · `token-queue` · `video-consultation` · `in-person-consultation` · `doctor-verification` |
| Trust & Safety | `consent-sharing` · `audit-security` · `human-review` · `rag-safety` |
| Standards & Data | `fhir-standards` · `datasets` · `training-evaluation` · `notifications` · `analytics` |
| Company & System | `mvp-roadmap` · `living-canvas` · `about` · `contact` |

## Build
```bash
node build.mjs      # regenerates public/*.html
```
Serve `public/` with any static server (Vercel, nginx, `python -m http.server`).

## Design & motion
Warm clinical minimalism (matte, low-contrast, shadows-not-glow) with the
**Living Health Canvas** — a 5-layer ambient animation (paper grain, contour
lines, pulse waveform, soft motes, slow geometry) — and 12 dependency-free
motion primitives. All motion respects `prefers-reduced-motion`.

## Auto-fit guarantee
Fluid `clamp()` type/spacing, `minmax(0,1fr)` grids, `svh`/`dvh` discipline,
safe-area insets, `pointer:coarse` touch targets, responsive card-collapse
tables. Verified against 320→2560px, Android/iOS *Desktop site* mode (~980px
touch layout), landscape and 200% zoom — nothing is clipped or uneven.

## Configuration
Copy `.env.example` → `.env` and fill the Supabase / Vercel / GitHub values.
Secrets are git-ignored; only `public/config/site.js` holds publishable values.
Planned backend schema (users, patients, doctors, doctor_credentials,
organizations, appointments, tokens, encounters, documents, observations,
prescriptions, consents, audit_events, ai_jobs, model_versions …) follows the
FHIR-aligned spec — see `RESEARCH_AND_BUILD_LOG.md` at the workspace root.
